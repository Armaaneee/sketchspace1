SketchSpace

A browser-based whiteboard tool.

Keyboard Shortcuts:

  • S - Select Tool
  • P - Pen Tool
  • E - Eraser Tool
  • T - Text Tool
  • F - Fill Bucket Tool
  • L - Line Tool
  • R - Rectangle Tool
  • O - Circle Tool
  • A - Arrow Tool
  • C - Clear Canvas
  • Ctrl+Z - Undo
  • Ctrl+Y - Redo
  • Ctrl/Cmd+C - Copy Selection
  • Ctrl/Cmd+V - Paste Selection
  • Mouse Wheel - Zoom In/Out
  • Space + Drag - Pan Canvas
